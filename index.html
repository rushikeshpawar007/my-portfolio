Why this approach

A difference is a starting point for investigation: timing and accounting treatment can explain it. The control makes exceptions visible so Finance and audit can review them; it does not treat every difference as lost revenue.

Implementation and forecasting logic
  1. 01
    Load and model daily

    AWS AppFlow brings Salesforce data into S3. Scheduled dbt runs build the reporting models on Athena each day.

  2. 02
    Retain historical versions

    Type 2 snapshots retain opportunity stage changes with validity periods, making days in stage and transitions available for analysis.

  3. 03
    Apply the history

    Historical stage-conversion rates inform a stage-weighted operating-income forecast for the open pipeline. This goes beyond simply summing current deal amounts.
